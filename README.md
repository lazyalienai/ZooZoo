# 🎬 Android OTT Streaming App

A full-featured **Android OTT (Over-the-Top)** streaming application for watching movies, series, and shows — built natively for Android users with modern UI and robust media playback capabilities.

## 📱 Key Features

- 🔐 User authentication (Login/Signup with JWT/Firebase Auth)
- 🎥 HD streaming of Movies, Web Series, and Shows
- 🧾 Watchlist & Favorites
- 🧠 Personalized recommendations
- 🔎 Search and filter by genre, language, etc.
- 🌐 Multi-language support
- 📆 Scheduled releases & push notifications
- 💳 Subscription plans & payment integration (Google Play Billing)
- ⏯️ Media player with subtitle and resolution controls
- 💬 In-app feedback and rating system

## 🛠️ Tech Stack

### Android (Frontend):
- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Networking**: Retrofit / OkHttp
- **Media Playback**: ExoPlayer
- **Architecture**: MVVM
- **Database**: Room / DataStore
- **Dependency Injection**: Hilt
- **Push Notifications**: Firebase Cloud Messaging
- **Analytics**: Firebase Analytics

### Backend (optional if integrated):
- Node.js / Django / Spring Boot
- MongoDB / PostgreSQL
- JWT Auth / Firebase Auth
- Cloudinary / AWS S3 for media storage
- Stripe / Razorpay for subscriptions
